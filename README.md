# AppLocker

A tiny Windows app that locks chosen apps (Chrome, Edge, anything) behind a master password.
A single ~500 KB `.exe` that lives in the tray, starts with Windows, and uses about 2 MB of RAM and ~0% CPU.

## Build

```powershell
cargo build --release
```

The result is `target\release\applocker.exe` (self-contained, no runtime needed). Copy it anywhere you like, for example
`C:\Program Files\AppLocker\`, and run it once.

## Use

1. On first run, set a master password. "Start with Windows" is turned on automatically.
2. In **Settings**, click **Add app...** and pick the program (for example
   `C:\Program Files\Google\Chrome\Application\chrome.exe`).
3. Every time that app starts, it is frozen and a password prompt appears.
   - Correct password: the app continues normally.
   - Cancel or 3 wrong tries: the app is closed.
4. The app stays unlocked until **all** of its windows/processes are closed, then it locks again.

Tray icon: double-click or right-click > **Settings**. **Exit** also asks for the password.

## How it works

| Part | File |
|---|---|
| Watcher: WinEvent hook on window creation, plus process handles for exit detection, plus a full scan every 5 s as a safety net | `src/monitor.rs` |
| Suspend / resume via `NtSuspendProcess` / `NtResumeProcess`, kill via `TerminateProcess` | `src/monitor.rs` |
| Password: Argon2id hash (one-way, only verified, never decrypted) | `src/crypto.rs` |
| Settings file `%APPDATA%\AppLocker\config.dat`, encrypted with Windows DPAPI | `src/config.rs` |
| Autostart: `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` | `src/startup.rs` |
| Native Win32 UI (tray, password dialog, settings) | `src/tray.rs`, `src/ui/` |

## Limitations

- Apps are matched by exe file name (`chrome.exe`), so any copy of that exe is locked too.
- It isn't tamper-proof. Ending `applocker.exe` in Task Manager or using Safe Mode gets around it.
  You can lock `Taskmgr.exe` too if you want.
- Apps running as administrator can't be frozen unless AppLocker also runs as administrator.
- If Chrome's *"Continue running background apps when Google Chrome is closed"* setting is on, Chrome never
  fully exits and won't re-lock. Turn it off.
- Forgot the password? Delete `%APPDATA%\AppLocker\config.dat` and set a new one on the next start.
